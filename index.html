Does this comply with Meta and Instagram's policies?

Yes, 100%. We publish strictly through Meta's official Content Publishing Graph API for Professional Creator/Business accounts. We do NOT perform any banned engagement botting (like auto-following or comment pods). Growth is driven purely by high-signal content retention.

Will this cost me anything in API or server bills?

Zero dollars. The engine is architected to utilize free AI tiers (Google Gemini 1,500 req/day free, Groq, or our built-in offline knowledge engine), free image rendering with local Chromium, free asset hosting tunnels, and free GitHub Actions runner minutes.
